# 利用シナリオ

## 1. 目的

この資料は、利用者がタスク管理アプリをどのように利用するかを、正常時と例外時の流れで定義する。機能要件の実装・確認時は、本資料と[機能要件](functional-requirements.md)を対応付ける。

## 2. 正常時のシナリオ

### US-01: 初回利用

1. 利用者がアプリを開く。
2. 保存済みデータが存在しない場合、未着手・進行中・完了のサンプルリストとカードを表示する。
3. 利用者はサンプルを編集、移動、削除して利用を開始できる。

### US-02: タスクを追加して進捗を更新する

1. 利用者がリストを追加する、または既存リストを選ぶ。
2. 利用者がカード名を入力してカードを追加する。
3. 作業の進捗に応じて、カードを同じリスト内または別リストへ移動する。
4. アプリは変更後の状態を保存する。

### US-03: 次回利用する

1. 利用者がアプリを再読み込みする、または後日アプリを開く。
2. アプリはlocalStorageから保存済みデータを読み込む。
3. 利用者は前回終了時のリスト・カードの状態から作業を再開する。

## 3. 例外時のシナリオ

### US-04: 入力が不正な場合

1. 利用者が空文字または空白だけの名前でリスト・カードを登録しようとする。
2. アプリは登録せず、入力欄の近くに理由を表示する。

### US-05: 移動を取り消す場合

1. 利用者がカードのドラッグを開始する。
2. 有効なドロップ先以外で終了する、または操作を取り消す。
3. アプリはカード位置と保存データを変更しない。

### US-06: 保存・復元に失敗する場合

1. localStorageへの保存または読み込みに失敗する。
2. アプリは画面を停止させず、保存失敗または初期状態で開始したことを通知する。
3. 保存失敗時は、利用者がブラウザの保存設定を確認できるよう案内する。
