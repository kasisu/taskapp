# 制約・前提

## 1. 前提

| 項目 | 内容 |
|---|---|
| 利用者 | 単一利用者のみ。 |
| 利用環境 | PCの最新Chrome。 |
| データ保存 | ブラウザのlocalStorage。 |
| 初期データ | 保存済みデータがない場合のみ、サンプルデータを表示する。 |
| データ内容 | 個人情報・機密情報を保存しない。 |

## 2. 制約

- 同じ端末・同じブラウザでのみデータを利用できる。
- ブラウザのサイトデータ削除、ブラウザ変更、端末変更によるデータ消失を防げない。
- 共同編集、ログイン、権限管理、複数端末同期は提供しない。
- ネットワーク通信、バックエンド、外部データベースは使用しない。
- Trelloのブランド資産や全機能を複製せず、基本操作モデルと視覚的階層のみを参照する。
- Trelloのロゴ、名称を識別子として用いるUI、固有アイコン、画像、文言、画面の完全複製は行わない。
- Trelloの一般的なカンバンボードの構造、情報階層、操作の開閉方式を参考にした独自UIとして実装する。
- 共有、公開範囲、検索、通知、拡張機能など、上部UIに表示する要素は今回のモックアップでは機能を持たない表示要素とする。

## 3. リスクと対応方針

| リスク | 影響 | 対応方針 |
|---|---|---|
| localStorageが利用できない・容量不足 | 変更を永続化できない | 画面を停止させず、保存失敗を通知する。 |
| 保存データの破損 | 復元できない | 初期サンプルで開始し、破損を通知する。 |
| 複数端末で使いたい要望 | データの不整合・同期不可 | 今回は対象外とし、将来はバックエンド導入を別要件として検討する。 |
